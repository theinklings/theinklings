# The Inklings

A welcoming creative collective landing page built with Node.js and Express.

## Running locally

```bash
npm install
npm start        # production mode
npm run dev      # development mode with nodemon
```

Open http://localhost:3000 in your browser.

## Project structure

- `server.js` — Express server entry point
- `public/` — Static client assets (HTML, CSS, JS, images)
- `package.json` — npm manifest and scripts
